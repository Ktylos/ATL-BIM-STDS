Type vs Instance — How to bind shared parameters in Revit:
Type parameters describe what the object is — manufacturing specs (model, voltage, capacity, material). All copies of the same Revit type share one value. Set these in the family type.
Instance parameters capture operational data for each individual element — IDs, serial numbers, dates, condition, location. These must be filled by the commissioning agent or installer for each placed element.
